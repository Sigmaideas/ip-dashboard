# 엑스와이지 IP 통합 관리 대시보드

주식회사 엑스와이지(XYZ, Inc.)가 보유한 지식재산권 — 특허 포트폴리오를 한 화면에서 관리하는 **회사 내부용** 대시보드입니다.
특허 건수·발명자·관련 특허군을 정리하고, 4개 축 기반의 간단한 기술평가를 함께 관리합니다.

디자인 컨셉과 색·타이포는 [loungex-brand-dashboard](https://github.com/Sigmaideas/loungex-brand-dashboard)와 동일하게 맞췄습니다.

---

## 화면 구성

| 뷰 | 내용 |
|---|---|
| **개요** | 전체/등록/출원중 건수, 발명자 수, 평균 평가점수 · 국가별·기술분류별 분포 · 연도별 출원·등록 추이 · 핵심 특허 TOP 5 |
| **특허 목록** | 검색(명칭·출원번호·발명자·IPC·요약) + 국가/상태/분류 필터 · 전 컬럼 정렬 · 클릭 시 상세 모달 |
| **관련 특허군** | 같은 기술 계열로 묶은 특허군별 보유 건수와 구성 특허 |
| **발명자** | 발명자별 참여 건수(등록/출원중 누적), 평균 평가점수, 주요 분야 |
| **기술평가** | 평가축별 평균 레이더 · 등급 분포 · 기술성×시장성 4분면 매트릭스 · 평가 랭킹 |

특허 상세 모달에서는 서지정보(출원·등록번호, 일자, 출원인, 발명자, IPC, 적용 제품), 요약,
기술평가 4축 점수와 의견, **같은 특허군에 속한 관련 특허** 목록을 볼 수 있습니다.

---

## 기술평가 기준

4개 축을 각 **5점 척도**로 평가하고, 입력된 축의 평균을 종합점수로 사용합니다.

| 축 | 평가 내용 |
|---|---|
| **기술성** | 기술 난이도·독창성 |
| **시장성** | 적용 시장의 규모·성장성 |
| **권리성** | 청구범위의 넓이·회피 난이도 |
| **활용도** | 자사 제품에 실제 적용된 정도 |

종합점수 → 등급: **S** 4.5↑ · **A** 3.5↑ · **B** 2.5↑ · **C** 그 미만.
한 축도 입력되지 않은 특허는 *미평가*로 남고 등급 대신 `–`로 표시됩니다. 평가 없이도 나머지 기능은 모두 동작합니다.

## 설치 및 실행

Node.js 18+ 필요.

```bash
npm install
npm run dev     # http://localhost:5174
```

> `dashboard/index.html`을 파일로 직접 열면(`file://`) 브라우저가 `fetch`를 막아 데이터가 로드되지 않습니다.
> 반드시 `npm run dev` 로 서버를 띄우거나 GitHub Pages 로 접속하세요.

## 특허 데이터 업데이트 (엑셀 임포트)

특허 원본은 엑셀로 관리하고, 임포터가 대시보드용 JSON으로 변환합니다.

```bash
# 1. 엑셀을 inbox/ 에 넣는다 (inbox 는 .gitignore 처리되어 리포에 올라가지 않음)
cp ~/Downloads/특허목록.xlsx inbox/

# 2. 먼저 --dry 로 컬럼 매핑이 맞는지 확인 (파일을 쓰지 않음)
npm run import -- inbox/특허목록.xlsx --dry

# 3. 문제 없으면 실제 변환 → data/patents.json 생성
npm run import -- inbox/특허목록.xlsx

# 시트가 여러 개면 지정
npm run import -- inbox/특허목록.xlsx --sheet "등록특허"
```

### 임포터가 알아서 처리하는 것

- **헤더 행 자동 탐지** — 엑셀 위쪽에 제목·기준일 같은 안내 문구가 몇 줄 있어도 실제 헤더 행을 찾습니다.
- **컬럼명 흔들림 흡수** — `발명의 명칭`/`명칭`/`특허명`, `출원일`/`출원일자` 등을 같은 필드로 인식합니다.
- **날짜 형식 혼재** — 엑셀 시리얼 넘버, `2020.06.08`, `2020-06-08` 을 모두 `YYYY-MM-DD` 로 정규화합니다.
- **상태·국가 표기** — `등록`/`registered`/`granted` → `registered`, `한국`/`KR` → `KR` 등으로 매핑하고,
  비어 있으면 등록번호 유무와 출원번호 형식으로 추정합니다.
- **평가 점수 척도 환산** — 100점·10점 척도로 적혀 있어도 5점 척도로 환산합니다.
- **미매핑 컬럼 보존** — 인식하지 못한 컬럼은 버리지 않고 각 특허의 `extra` 에 담아 둡니다.
  나중에 `scripts/import-excel.js` 의 `COLUMN_ALIASES` 에 별칭만 추가하면 바로 반영됩니다.

임포트 후 콘솔에 인식된 컬럼 매핑, 건수 요약, 그리고 **명칭·출원일·발명자가 비어 있는 건수**가 출력되니
확인 후 원본 엑셀을 보완하면 됩니다.

### 엑셀 권장 컬럼

필수는 **발명의 명칭** 하나뿐이고, 나머지는 있으면 반영됩니다.

```
발명의 명칭 | 국가 | 권리상태 | 출원번호 | 출원일자 | 등록번호 | 등록일자 |
출원인 | 발명자 | IPC | 기술군 | 기술분류 | 적용제품 | 요약 |
기술성 | 시장성 | 권리성 | 활용도 | 평가의견
```

- **발명자**가 여러 명이면 쉼표(`,`)로 구분합니다.
- **기술군**은 관련 특허를 묶는 기준입니다. 같은 값을 가진 특허끼리 "관련 특허"로 연결됩니다.
- **기술성~평가의견**은 비워 두면 미평가로 남습니다. 대시보드를 보면서 나중에 채워도 됩니다.

## 데이터 구조

`data/patents.json` 한 파일에 모두 들어 있습니다. 엑셀 없이 이 파일을 직접 수정해도 됩니다.

```json
{
  "meta": { "company": "주식회사 엑스와이지", "lastUpdated": "...", "source": "특허목록.xlsx" },
  "patents": [
    {
      "id": "P001",
      "title": "커피 드립 동작을 위한 로봇 팔 제어 방법",
      "country": "KR",
      "status": "registered",
      "applicationNumber": "10-2020-0069000",
      "applicationDate": "2020-06-08",
      "registrationNumber": "10-2400000",
      "registrationDate": "2022-05-18",
      "applicant": "주식회사 라운지랩",
      "inventors": ["황성재", "김로봇"],
      "ipc": ["B25J 11/00"],
      "family": "드립 커피",
      "category": "로봇제어",
      "productLine": ["바리스드립"],
      "abstract": "...",
      "evaluation": {
        "technology": 5, "marketability": 4, "rights": 4, "utilization": 4,
        "comment": "핵심 차별화 기술."
      }
    }
  ]
}
```

`status`: `registered` · `pending` · `rejected` · `abandoned` · `expired`
`country`: `KR` · `US` · `CN` · `JP` · `EP` · `WO`

> **사명 변경 이력** — 엑스와이지는 이전에 *라운지랩*이었습니다. 초기 출원 건은 출원인이
> `주식회사 라운지랩`으로 남아 있으므로, 출원인 기준으로 필터링할 때 두 이름을 함께 봐야 합니다.
> `meta.companyAliases` 에 알려진 표기를 모아 두었습니다.

## 주의사항

- 본 대시보드와 데이터는 **회사 내부 IP 관리 목적**으로만 사용합니다.
- 원본 특허 엑셀은 `inbox/` 에 두며 `.gitignore` 로 리포에서 제외됩니다. 변환 결과인 `data/patents.json` 만 커밋합니다.
- 기술평가 점수는 **내부 검토용 참고 지표**이며, 정식 특허 가치평가(기술가치평가기관 평가)를 대체하지 않습니다.
  투자·거래·담보 목적에는 별도의 공식 평가가 필요합니다.

## 파일 구조

```
ip-dashboard/
├── dashboard/          # 대시보드 프론트엔드
│   ├── index.html
│   ├── app.js          # 렌더링·차트·필터·정렬 전부
│   ├── style.css       # loungex-brand-dashboard 와 동일한 디자인 토큰
│   └── logo.png
├── data/
│   └── patents.json    # 유일한 데이터 소스
├── scripts/
│   └── import-excel.js # 엑셀 → patents.json 변환
├── inbox/              # 원본 엑셀 보관 (git 제외)
└── server.js           # 로컬 정적 서버
```

`app.js` / `style.css` 를 수정하면 `dashboard/index.html` 의 `?v=` 캐시 버스팅 숫자도 함께 올려 주세요.
GitHub Pages 가 `max-age=600` 으로 내려주기 때문에 바꾸지 않으면 10분간 옛 파일이 그대로 쓰입니다.

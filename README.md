# 엑스와이지 IP 통합 관리 대시보드

주식회사 엑스와이지(XYZ, Inc.)가 보유한 지식재산권 — 특허·상표·디자인·저작권을 한 화면에서 관리하는 **회사 내부용** 대시보드입니다.
보유 현황과 발명자·관련 특허군을 정리하고, 특허에 대해서는 4개 축 기반의 간단한 기술평가를 함께 관리합니다.

디자인 컨셉과 색·타이포는 [loungex-brand-dashboard](https://github.com/Sigmaideas/loungex-brand-dashboard)와 동일하게 맞췄습니다.

---

## 현재 보유 현황

태창특허법률사무소와 공유하는 「통합 관리 시트」 기준 **총 161건**입니다.

| 권리 | 건수 | | 상태 | 건수 | | 국가 | 건수 |
|---|---:|---|---|---:|---|---|---:|
| 상표 | 93 | | 등록 | 114 | | KR | 121 |
| 특허 | 56 | | 출원 | 21 | | CN | 16 |
| 디자인 | 11 | | 거절 | 13 | | US | 13 |
| 저작권 | 1 | | PCT | 6 | | PCT | 8 |
| | | | 심사중 | 4 | | JP · SG · IN | 각 1 |
| | | | 이관 · 포기 | 3 | | | |

특허 56건은 **26개 발명**으로, 같은 발명이 KR·US·CN·PCT로 나뉘어 출원된 패밀리 구조입니다.
발명자는 13명이며 **황성재**(카페·서비스 로봇)와 **민중후**(물류·방역 로봇) 두 계열로 나뉩니다.

## 기술평가

4개 축을 각 **5점 척도**로 평가하고, 입력된 축의 평균을 종합점수로 사용합니다.

| 축 | 평가 내용 |
|---|---|
| **기술성** | 기술 난이도·독창성 |
| **시장성** | 적용 시장의 규모·성장성 |
| **권리성** | 청구범위의 넓이·회피 난이도 |
| **활용도** | 자사 제품에 실제 적용된 정도 |

종합점수 → 등급: **S** 4.5↑ · **A** 3.5↑ · **B** 2.5↑ · **C** 그 미만.

평가는 **특허 패밀리 단위**로 매깁니다. 같은 발명의 KR·US·CN 대응 건은 내용이 동일하므로 하나의 평가를 공유합니다.
평가값은 `data/evaluations.json` 에 패밀리명을 키로 저장되며, 임포트 시 각 특허에 붙습니다.

> ⚠️ 현재 들어 있는 평가는 **내부 검토용 초안**입니다. 출원국 수(회사가 실제로 비용을 투입한 정도),
> 현 제품라인 적용 여부, 기술 난이도, 시장 상황을 근거로 매겼습니다.
> 정식 기술가치평가(기술가치평가기관 평가)를 대체하지 않으며, 투자·거래·담보 목적에는 별도의 공식 평가가 필요합니다.
> **검토 후 `data/evaluations.json` 을 직접 수정**하고 임포트를 다시 실행하세요.

## 설치 및 실행

Node.js 18+ 필요.

```bash
npm install
npm run dev     # http://localhost:5174
```

> `dashboard/index.html`을 파일로 직접 열면(`file://`) 브라우저가 `fetch`를 막아 데이터가 로드되지 않습니다.
> 반드시 `npm run dev` 로 서버를 띄우거나 GitHub Pages 로 접속하세요.

## 데이터 업데이트 (엑셀 임포트)

원본은 Google Drive의 **`특허상표디자인 리스트_엑스와이지(w/태창특허법률사무소).xlsx`** 이며,
그 안의 **「통합 관리 시트」** 를 기준으로 변환합니다.

```bash
# 1. 엑셀을 inbox/ 에 넣는다 (inbox 는 .gitignore 처리되어 리포에 올라가지 않음)
cp ~/Downloads/특허상표디자인*.xlsx inbox/

# 2. 먼저 --dry 로 컬럼 매핑과 건수를 확인 (파일을 쓰지 않음)
npm run import -- "inbox/특허상표디자인 리스트_엑스와이지.xlsx" --dry

# 3. 문제 없으면 실제 변환 → data/rights.json 생성
npm run import -- "inbox/특허상표디자인 리스트_엑스와이지.xlsx"

# 다른 시트를 쓰려면
npm run import -- <파일> --sheet "엑스와이지부산"
```

### 임포터가 처리하는 것

- **헤더 행 자동 탐지** — 시트 위쪽에 안내 문구가 있어도 실제 헤더 행을 찾습니다.
- **날짜 정규화** — 엑셀 시리얼 넘버를 직접 변환합니다. `cellDates` 옵션을 쓰면 UTC 기준으로 해석돼
  KST 날짜가 하루 밀리므로(2015-03-02 → 03-01) 의도적으로 끄고 처리합니다.
- **권리·상태·국가 매핑** — `특허/상표/디자인/저작권`, `등록/출원/심사중/PCT/거절/포기/이관`,
  `한국·싱가폴·인도` → `KR·SG·IN` 등으로 정규화합니다.
- **발명자 전개** — `민중후(정승교, 박혁, 김희철)` 같은 대표+괄호 표기를 개별 발명자로 펴고,
  상표의 `N/A` 는 빈 값으로 둡니다.
- **패밀리 자동 도출** — 명칭을 정규화해 같은 발명끼리 묶습니다. 명칭이 조금씩 달라 자동으로 안 묶이는 건은
  `FAMILY_MERGE` 규칙으로 병합합니다 (예: `위험도 판단에 기초한 로봇 팔/움직임/이동 로봇` → 하나의 안전제어 패밀리).
- **증서 파일명 수집** — 헤더가 비어 있는 꼬리 컬럼의 PDF 파일명을 `docRef` 로 건집니다.
- **미매핑 컬럼 보존** — 인식 못 한 컬럼은 버리지 않고 `extra` 에 담습니다.
  `COLUMN_ALIASES` 에 별칭만 추가하면 바로 반영됩니다.

임포트 후 콘솔에 **명칭·출원일이 비어 있는 건**이 출력되니 원본 엑셀 보완에 활용하세요.

## 알려진 데이터 이슈

원본 시트에서 확인이 필요한 항목입니다.

1. **명칭 누락** — `US 17/544,095` (2021-12-07 출원, 등록) 의 명칭이 비어 있어 패밀리 분류·평가·키워드 집계에서 빠집니다.
   키워드 화면의 `미분류` KPI 가 이 건입니다.
2. **저작권 출원일 누락** — `작업자 선도 방식의 스마트 물류 이송 로봇` (C-2021-053038) 에 출원일이 없습니다.
3. **DUE DATE 의미 혼재** — 권리별로 기준이 다릅니다.
   - 특허: 등록일 +3년 = 다음 연차등록료 납부기한 (등록 시 3년분 일괄납부 후 4년차부터)
   - 상표: 등록일 +10년 = 갱신기한
   - PCT: 국내단계 진입기한
   - **14건은 DUE DATE 가 등록일과 동일**해 실제 기한이 아니라 등록일이 복사된 것으로 보입니다.
     기준이 이렇게 뒤섞여 있어 기한 관리 화면은 두지 않았습니다. 개별 DUE DATE 는 권리 상세에서 확인합니다.
4. **연차료 납부 현황이 비고란에 기재** — `연차등록료 납부현황` 컬럼은 비어 있고 실제 내용은 `비고` 에 있습니다.
   자유 서술이라 기계적으로 판정할 수 없으므로 **실제 납부 여부는 특허사무소 확인이 필요합니다.**
5. **출원인 표기 흔들림** — `주식회사 엑스와이지` / `주식회사엑스와이지` (띄어쓰기), 그리고
   `주식회사 엑스와이지부산` · `주식회사 코봇` 계열이 섞여 있습니다.

## 데이터 구조

`data/rights.json` 한 파일에 모두 들어 있습니다.

```json
{
  "meta": { "company": "주식회사 엑스와이지", "lastUpdated": "...", "source": "...xlsx", "sheet": "통합 관리 시트" },
  "rights": [
    {
      "id": "PT002",
      "type": "patent",
      "mgmtNo": "GTD1905001",
      "title": "커피 드립을 수행하는 로봇 팔 제어 방법 및 제어 시스템",
      "country": "KR",
      "status": "registered",
      "applicant": "주식회사 엑스와이지",
      "inventors": ["황성재"],
      "niceClass": null,
      "applicationNumber": "10-2019-0070010",
      "applicationDate": "2019-06-13",
      "registrationNumber": "10-2206415",
      "registrationDate": "2021-01-26",
      "dueDate": "2026-01-26",
      "family": "커피 드립을 수행하는 로봇 팔 제어 방법 및 제어 시스템",
      "notes": "4년차 연차등록료 납부",
      "docRef": "[특허][10-2206415] ....pdf",
      "evaluation": { "technology": 5, "marketability": 4, "rights": 4, "utilization": 5, "comment": "..." }
    }
  ]
}
```

`type`: `patent` · `trademark` · `design` · `copyright`
`status`: `registered` · `pending` · `examining` · `pct` · `rejected` · `abandoned` · `transferred`

> **사명 변경 이력** — 엑스와이지의 이전 사명은 *라운지랩*이며, 라운지엑스(LOUNGE'X)는 별도 법인이 아니라
> 엑스와이지가 운영하는 로봇 카페 **브랜드**입니다. 출원인 기준으로 집계할 때는
> `meta.companyAliases` 의 표기를 함께 봐야 누락이 없습니다.

## 주의사항

- 본 대시보드와 데이터는 **회사 내부 IP 관리 목적**으로만 사용합니다.
- 원본 엑셀은 `inbox/` 에 두며 `.gitignore` 로 리포에서 제외됩니다. 변환 결과인 `data/rights.json` 만 커밋합니다.
- 기술평가 점수는 내부 검토용 참고 지표입니다 (위 [기술평가](#기술평가) 항목 참고).

## 파일 구조

```
ip-dashboard/
├── dashboard/
│   ├── index.html
│   ├── app.js            # 렌더링·차트·필터·정렬
│   ├── style.css         # loungex-brand-dashboard 와 동일한 디자인 토큰
│   └── logo.png
├── data/
│   ├── rights.json       # 대시보드가 읽는 유일한 데이터 파일 (임포터가 생성)
│   └── evaluations.json  # 특허 패밀리별 기술평가 (직접 관리)
├── scripts/
│   └── import-excel.js   # 엑셀 → rights.json 변환
├── inbox/                # 원본 엑셀 보관 (git 제외)
└── server.js             # 로컬 정적 서버
```

`app.js` / `style.css` 를 수정하면 `dashboard/index.html` 의 `?v=` 캐시 버스팅 숫자도 함께 올려 주세요.
GitHub Pages 가 `max-age=600` 으로 내려주기 때문에 바꾸지 않으면 10분간 옛 파일이 그대로 쓰입니다.
